# DME Study Hub

DME Study Hub is a front-end web platform designed to help Digital Media Engineering students share academic resources with one another. The platform allows seniors to upload past assignments, notes, and study materials, making it easier for juniors to prepare for exams and understand key course content.

This project focuses on UI/UX design and front-end development, providing a clean, organized, and student-friendly interface.

## 🚀 Features
- Browse academic materials by category  
- View past assignments, notes, and exam references  
- Simple, intuitive navigation for students  
- UI built with clean layout and responsive structure (front-end only)  
- Designed for future backend integration  

## 🛠️ Technologies Used
- **HTML**
- **CSS**
- **JavaScript**

## 📘 Project Purpose
This project was created as a personal initiative to support students in the Digital Media Engineering program at Khon Kaen University by providing a central resource-sharing platform.  
The current version is a front-end prototype showcasing user journeys and interface design.

## 📂 Status
The project is still in development.  
Future updates may include:
- Backend integration  
- User authentication  
- File upload system  
- Search and filtering features
